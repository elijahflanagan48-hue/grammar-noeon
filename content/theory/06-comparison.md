# Degrees of Comparison

## Карта раздела

| Задача | Конструкция | Пример |
| --- | --- | --- |
| Больше / выше / лучше | comparative + than | This room is brighter than ours. |
| Самый в группе | the + superlative | the brightest room in the building |
| Такой же | as + adjective + as | as bright as this room |
| Менее | not as + adjective + as | not as bright as this room |
| Насколько отличается | much / slightly + comparative | slightly brighter |
| Всё больше | comparative + and + comparative | brighter and brighter |
| Чем …, тем … | the + comparative … the + comparative | The brighter the room, the easier it is to read. |

## Формы и орфография

| Модель | Positive | Comparative | Superlative |
| --- | --- | --- | --- |
| Один слог: + -er / -est | tall | taller | tallest |
| Конечная -e: + -r / -st | wide | wider | widest |
| Короткая гласная + согласная: удвоение | big / hot / thin | bigger / hotter / thinner | biggest / hottest / thinnest |
| Без удвоения | new / slow / cheap | newer / slower / cheaper | newest / slowest / cheapest |
| Согласная + -y → -i- | busy / happy | busier / happier | busiest / happiest |
| Длинное прилагательное | useful | more useful | most useful |
| Один способ образования | easy / tall | easier, не more easier | tallest, не most tallest |

:::note Если форма вызывает сомнение
Число слогов — ориентир. Варианты зависят от конкретного слова и значения; спорную форму проверяйте по словарю.
:::

## Два слога и варианты

| Тип / слово | Comparative | Superlative |
| --- | --- | --- |
| easy / heavy | easier / heavier | easiest / heaviest |
| careful / boring / patient | more careful / more boring / more patient | most careful / most boring / most patient |
| clever / narrow / simple / quiet | cleverer / more clever; narrower / more narrow; simpler / more simple; quieter / more quiet | cleverest / most clever; narrowest / most narrow; simplest / most simple; quietest / most quiet |
| polite / pleasant / common | politer / more polite; pleasanter / more pleasant; commoner / more common | politest / most polite; pleasantest / most pleasant; commonest / most common |
| tired / bored | more tired / more bored | most tired / most bored |
| lovely / silly | lovelier / sillier | loveliest / silliest |
| cosy / cozy | cosier / cozier | cosiest / coziest |
| grey / shy / dry | greyer / shyer / drier (также dryer) | greyest / shyest / driest |
| unhappy | unhappier / more unhappy | unhappiest / most unhappy |

## Неправильные формы

| Positive | Comparative | Superlative | Значение |
| --- | --- | --- | --- |
| good / well | better | best | хороший / хорошо; well — также о здоровье |
| bad / ill | worse | worst | плохой / плохо себя чувствующий |
| far | farther / further | farthest / furthest | расстояние |
| little | less | least | количество: less luggage |
| few | fewer | fewest | исчисляемое количество: fewer bags |
| much / many | more | most | количество |
| small | smaller | smallest | размер: a smaller bag |

:::note Ill и well
В значении здоровья возможна также оценка степени болезни more ill. Good — прилагательное, well обычно наречие; выбор зависит от функции в предложении.
:::

## Составные прилагательные

| Positive | Comparative | Superlative |
| --- | --- | --- |
| well-informed | better-informed / more well-informed | best-informed / most well-informed |
| well-educated / well-designed | better-educated / more well-educated; better-designed / more well-designed | best-educated / most well-educated; best-designed / most well-designed |
| well-read | better-read / more well-read | best-read / most well-read |
| good-looking | better-looking / more good-looking | best-looking / most good-looking |
| ill-informed | more ill-informed | most ill-informed |
| cost-effective / time-consuming | more cost-effective / more time-consuming | most cost-effective / most time-consuming |
| well off | better off | best off |

:::note Значение и дефис
Better off — более благоприятное положение, не обязательно богатство. Перед существительным: a better-informed panel; после связки: They are better off. У well-read и ill-informed выбор модели зависит от смысла. More better-informed — двойная сравнительная форма.
:::

## Older и elder

| Форма | Где используется | Пример |
| --- | --- | --- |
| older / oldest | Люди и предметы | an older neighbour; the oldest bridge |
| elder / eldest | Обычно семья, перед существительным | her elder brother; their eldest child |
| older + than | Прямое сравнение возраста | My sister is older than me. |
| older / elder | Оба варианта в семейном определении | her older sister / her elder sister |

## Farther и further

| Значение | Формы | Пример |
| --- | --- | --- |
| Физическое расстояние | farther / further; farthest / furthest | We walked farther / further. |
| Дополнительный | further | further details; further discussion |

## Сравнительная степень и than

| Модель | Пример | Смысл |
| --- | --- | --- |
| comparative + than | A tram is quieter than a motorbike. | Сравнение двух участников |
| comparative без than | Could we use a quieter room? | Точка отсчёта понятна |
| than + объектное местоимение | taller than me | Обычный разговорный вариант |
| than + подлежащее + глагол | taller than I am | Полная конструкция |
| Выбор признака | bigger / older / longer / more | Размер / возраст / длина / количество |

## Превосходная степень и группа

| Конструкция | Пример | Граница сравнения |
| --- | --- | --- |
| the + superlative + in | the quietest room in this hotel | Место / организация |
| the + superlative + of | the cheapest of the three options | Названное множество |
| superlative + of + период | the busiest day of the week | Время |
| the + comparative + of the two | the cheaper of the two | Традиционная формальная модель для двух |
| joint + superlative | the joint safest design | Разделённое первое место |

:::note Что означает «самый»
Группа должна быть названа или понятна. Суперлатив допускает нескольких участников с одинаковым лучшим результатом. При сравнении двоих в разговорной речи встречается и превосходная степень.
:::

## Артикли и определители

| Модель | Пример | Смысл / порядок |
| --- | --- | --- |
| the + superlative + noun | the best route | Лучший в группе |
| possessive + superlative + noun | my best friend | Без дополнительного the |
| one of the + superlative + plural noun | one of the safest routes | Один из; routes во множественном числе |
| the + ordinal + superlative | the second-largest island | Второе место; не second most largest |
| superlative после связки | Which route is safest? | The иногда опускается |
| most + adjective: один объект | This garden is most beautiful in early summer. | Лучшее состояние этого сада |
| at its + superlative | The guide is at its most useful during fieldwork. | Тот же объект в лучших условиях |
| a most + adjective + noun | a most helpful reply | Очень; формальный стиль |
| most + adjective + plural noun | most helpful suggestions | Весьма полезные |
| most + noun | most suggestions | Большинство |

## Равенство и неравенство

| Смысл | Конструкция | Пример |
| --- | --- | --- |
| Такой же | as + positive + as | This desk is as wide as that one. |
| Менее | not as / not so + positive + as | The corridor is not as wide as the hall. |
| Дороже | not as cheap as | A is not as cheap as B. |
| Дешевле | not as expensive as | A is not as expensive as B. |
| Форма внутри рамки | as wide as | Не as wider as; сохраняются оба as |

## Too и enough

| Конструкция | Пример | Значение |
| --- | --- | --- |
| too + adjective | too narrow for the trolley | Слишком; превышен подходящий предел |
| very + adjective | very narrow | Очень; без вывода о пригодности |
| adjective + enough | wide enough | Достаточно широкий |
| not + adjective + enough | not wide enough | Недостаточно широкий |
| adjective + enough + to + infinitive | wide enough to let it through | Достаточная степень для действия |
| adjective + enough + for + noun | wide enough for the trolley | Достаточная степень для объекта |
| sufficiently + adjective | sufficiently wide | Достаточно; формальный вариант |
| enough + noun | enough panels | Достаточно панелей: количество |
| adjective + enough + noun | wide enough panels | Панели достаточной ширины |

## Less и least

| Конструкция | Пример | Смысл |
| --- | --- | --- |
| less + adjective + than | less predictable than before | Меньшая степень |
| the least + adjective | the least predictable result | Наименьшая степень в группе |
| not as + короткое прилагательное + as | not as tall as me | Часто естественнее, чем less tall |
| the least expensive | the least expensive of these options | Самый дешёвый в этой группе; не обязательно дешёвый вообще |
| less + неисчисляемое / fewer + исчисляемое | less water / fewer mistakes | Количество |
| less than + единая величина | less than ten minutes | Время, расстояние или сумма как одно целое |

## Насколько велика разница

| Разница | Усилитель + comparative | Пример |
| --- | --- | --- |
| Значительная | much / far / a lot / considerably / substantially | much better; far more useful |
| Небольшая | a little / a bit / slightly / marginally | slightly cheaper; a bit taller |
| Дополнительное усиление | even / still | even better; still cheaper |
| Точная величина | число + единица + comparative | ten centimetres taller; two years older |
| Ошибка модели | не very + comparative | much better, не very better |

## Модификаторы равенства и кратность

| Конструкция | Пример | Смысл |
| --- | --- | --- |
| just / exactly as … as | exactly as wide as B | Точное равенство |
| almost / nearly as … as | almost as wide as B | Почти равенство |
| not quite as … as | not quite as wide as B | Немного не достигает |
| not nearly / nowhere near as … as | nowhere near as wide as B | Далеко не такая степень |
| twice / three times as … as | twice as wide as B | Вдвое / втрое |
| half as … as | half as expensive as B | Вдвое меньше по данной шкале |
| a third / one third as … as | a third as long as B | Отношение 1:3 |
| число + единица + comparative | three metres longer than B | Разница, а не коэффициент |

:::note Кратность
Twice as wide as — однозначная учебная модель. Обороты вроде twice bigger than могут пониматься неодинаково; в точном числовом сравнении сохраняйте явно заданное отношение.
:::

## Постепенное изменение

| Модель | Пример | Значение |
| --- | --- | --- |
| comparative + and + comparative | colder and colder | Всё холоднее |
| more and more + adjective | more and more useful | Всё полезнее |
| less and less + adjective | less and less reliable | Всё менее надёжный |
| Без than | It is getting colder and colder. | Изменение во времени, не второй участник |

## Связанные изменения

| Модель | Пример | Значение |
| --- | --- | --- |
| the + comparative … the + comparative | The harder you work, the better you get. | Чем …, тем … |
| the more … the less … | The more I read, the less certain I am. | Одно растёт, другое уменьшается |
| Сокращённая модель | The sooner, the better. | Чем раньше, тем лучше |

## Точность сравнения и пропуски

| Сравниваем | Конструкция / пример | Смысл |
| --- | --- | --- |
| Однотипные объекты | My room is larger than yours. | Моя комната и твоя комната |
| Свойства объектов | The population of A is larger than that of B. | Население A и население B |
| Множественные объекты | The streets here are wider than those in my town. | Those заменяет streets |
| Предсказуемый глагол | better than expected | better than people expected |
| Полная часть с be | more careful than I am | Не механическое do |
| Полная часть с глаголом | more reliable than I expected | Сохраняется нужное сказуемое |
| Два объекта симпатии | Mina likes Alex more than she likes Jo. | Alex и Jo |
| Два субъекта симпатии | Mina likes Alex more than Jo does. | Mina и Jo |

:::note Неоднозначный пропуск
Mina likes Alex more than Jo допускает оба последних прочтения. Если смысл важен, используйте полную часть. Yours / mine уже заменяют притяжательное сочетание с существительным.
:::

## Отрицание и логические границы

| Конструкция | Значение | Граница |
| --- | --- | --- |
| not taller than | Не выше | Ниже или равно |
| shorter than | Ниже | Строго меньше |
| no / not more expensive than | Не дороже | Равно или дешевле |
| no / not cheaper than | Не дешевле | Равно или дороже |
| no less reliable than | Не менее надёжный | Равно или надёжнее |
| at most / no more than 30 mm | Не больше 30 мм | 30 включено |
| at least / no less than 30 mm | Не меньше 30 мм | 30 включено |
| less than / more than 30 mm | Меньше / больше 30 мм | 30 исключено |
| taller than any other student | Выше любого другого ученика | Other исключает самого участника |
| not any + comparative | not any clearer | Не яснее; не not any no |

:::note Оценка, а не число
No better than может означать «ничем не лучше». Значение зависит от контекста. As tall as само по себе не устанавливает первенство во всей группе.
:::

## Пределы шкалы и контекст

| Значение | Конструкция / пример | Ограничение |
| --- | --- | --- |
| Градуируемый признак | cold → colder | Есть шкала |
| Буквальный статус | married | Обычно не сравнивается по степени |
| Полнота / приближение к идеалу | a more complete account; a more perfect arrangement | Контекстная оценка |
| Управление to | senior / junior / superior / inferior / preferable to | superior to the old model |
| Положение в иерархии | more senior than | Отдельная допустимая модель |
| Два качества одного объекта | more defensive than informative | Скорее защитный, чем информативный |

## Устойчивые сравнения

| Конструкция | Пример | Значение |
| --- | --- | --- |
| the lesser of two evils | choose the lesser of two evils | Меньшее из двух зол |
| the more, the merrier | The more, the merrier. | Чем больше людей, тем веселее |
| as … as: устойчивые обороты | as fit as a fiddle; as blind as a bat | В отличной форме; очень плохо видящий |
| none the + comparative | none the wiser | Понимать не больше прежнего |
| all the + comparative | all the stronger / all the more useful | Тем сильнее / полезнее по этой причине |
| more + positive + than | more dry than stiff | Скорее сухой, чем жёсткий |
| not so much … as | not so much angry as disappointed | Не столько злой, сколько разочарованный |
| more of a + noun + than | more of a problem than a solution | Скорее проблема, чем решение |
| as + adjective + a/an + noun + as | as practical a solution as yours | Порядок прилагательного и артикля |
| so + adjective + a/an + noun + as to | so urgent an issue as to require action | Степень и следствие |
| so … that / such a/an … that | so cold that we stayed in; such a cold day that we stayed in | Степень и следствие |

## Проверка перед ответом

| Проверка | Что сохранить |
| --- | --- |
| Признак | Возраст, размер, цена, качество или количество |
| Участники | Кто с кем сравнивается; границы группы |
| Форма | Positive / comparative / superlative |
| Конструкция | Порядок the / than / as и усилителя |
| Смысл | Направление, отрицание, величина различия, регистр |
| Поле ответа | Только недостающие слова по инструкции |

:::note Что вводить в упражнении
Следуйте инструкции: иногда нужна форма, иногда сочетание целиком. Уже напечатанные the, much, than не повторяйте. При требовании AS ответ может включать оба as. В преобразовании сохраняйте заданное начало и ключевое слово.
:::

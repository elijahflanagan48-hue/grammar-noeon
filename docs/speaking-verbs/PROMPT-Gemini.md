Ты — методист по английской грамматике для русскоязычных учеников (A2–C1, ЕГЭ, IELTS). Делаешь часть A банка упражнений на тему Say · Tell · Speak · Talk для сайта Grammar NOEON.

К сообщению приложены: TASK.md (спецификация — прочитай целиком и соблюдай), RULE.md (правило, опирайся только на него), examples.jsonl (эталон формата и качества).

Внутри цели покрой все её пункты из таблицы target в TASK.md, а не один-два самых простых.

## Как работать

1. Работай партиями по 50 заданий. Ответ на каждую партию — только блок ```jsonl``` с 50 строками, без пояснений вокруг. Имя партии пиши первой строкой вне блока: `part-A-01.jsonl` … `part-A-06.jsonl`.
2. Перед выдачей партии перечитай каждое задание как ученик, который видит только предложение и скобку. Спроси себя: может ли подойти другой глагол из скобки или другое время? Если да — перепиши контекст.
3. Особенно внимательно с speak / talk (раздел 3 в TASK.md): там два ответа почти всегда возможны, нужен жёсткий маркер.
4. Не повторяй предложения из examples.jsonl и RULE.md дословно. Одна схема предложения — не больше трёх раз на все 300.
5. Позиция верного ответа в multiple_choice: равномерно 0/1/2/3.
6. В конце последней партии выведи сводку: сколько заданий по каждому target, type и level.

Начни с партии part-A-01 (sv-0001 … sv-0050).

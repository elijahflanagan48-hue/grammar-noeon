## Обновление материалов

Исходные редакционные материалы не хранятся в этом репозитории. Публичный набор пересобирается из отдельного рабочего каталога:

```bash
python3 scripts/import_content.py --source /path/to/grammar-noeon
```

Импорт переносит только записи с `publishable: true`, удаляет внутренние сведения об источниках и делит банк упражнений на небольшие статические файлы. Проверка фиксирует ожидаемые объёмы и не пропускает служебные поля.

## Автономные локальные кабинеты

Для входа, учеников и серверного сохранения запустите из папки приложения:

```bash
python3 -B run.py --port 4175 --data-dir ../../private/grammar-accounts-local-2026-10-26
```

Откройте `http://127.0.0.1:4175/#profile`. Для первого учителя нужен код из `owner-setup-code.txt` в указанной папке данных. Имя, почту и пароль владелец задаёт сам. Ученики регистрируются по ссылкам, созданным учителем. База самостоятельная, без связи с другими приложениями. Не указывайте действующие базы других проектов.

Для отдельной демонстрации с вымышленными учениками: `python3 -B run.py --port 4177 --demo`. Данные демонстрации временные.

Проверки сервера и редакционных исправлений: `python3 -B -m unittest discover -s tests -p 'test_*.py'`.

[Реализация, запуск, проверки и ограничения](docs/reports/ACCOUNTS-2026-10-26.md).

Проверка и сохранение практики выполняются сервером. Ученики выполняют только назначения; полный банк доступен вошедшему учителю. Гостевой запуск закрыт. Прежняя история сохраняется для чтения. В сетевой версии вход и восстановление пароля обслуживает отдельный Firebase; локальные приглашения работают только на этом компьютере.

Теория использует British English. Уровни CEFR являются редакционной оценкой сложности, а не результатом внешней сертификации.

# Правила лексики для заданий (обязательны для всех тем)

Мы тренируем грамматику, а не словарь. Незнакомое слово не должно мешать ученику понять предложение и выбрать форму.

## Что допустимо по уровням

| Уровень в банке | Лексика | Редкие слова в задании |
|---|---|---|
| basic (A2) | только слова A1–A2 и очень частотные бытовые слова | 0, не более 2 слов уровня B1 |
| medium (B1) | слова A1–B1 | 0–1 редкое слово, не более 3 слов уровня B2 |
| advanced (B2+) | слова до B2, отдельные C1 по необходимости | не более 2 редких слов |

Редкое слово = слово уровня C1/C2 по списку CEFR или слово, которого нет в частотных списках (Zipf < 3,8), кроме имён собственных и грамматических терминов, которые нужны самому заданию (preposition, quantifier).

## Что запрещено

- Узкая лексика профессий и хобби: ремесло, музыка, наука, техника, юриспруденция, медицина, кулинария («kiln», «foundry», «arborist», «mimeograph», «locum»).
- Редкие животные и растения, экзотическая еда и вещи («squirrel», «ibex», «dumplings», «porcelain»), если тема не про них.
- Устаревшие и литературные слова, исторические реалии.
- Глагол в скобках должен быть из 1500 самых частотных. Редкий глагол в скобках (`to coax`, `to prune`, `to descale`) запрещён: ученик решает, как поставить форму, а не что значит слово.
- Сюжеты — обычная жизнь: дом, школа, работа, дорога, магазин, друзья, поездки, спорт, интернет. «Необычное» делается через ситуацию, а не через редкие слова.

## Как проверяется

`python3 scripts/lexical_audit.py <тема> --list 20` печатает задания, где лексика выше уровня, и самые частые трудные слова.
В `npm run check` включён `--gate 0.05` для пассива: не больше 5% заданий выше лимита. Для каждой новой темы после переделки добавляйте такую же строку в `scripts/check-all.mjs`.
Зависимости: `pip install wordfreq cefrpy` (в GitHub Actions уже подключены; без них проверка пропускается).

## Что вставлять в промпт для Gemini

> Лексика: пиши так, как для A2–B1. Используй только простые бытовые слова. Не используй редкие существительные, прилагательные и глаголы (примеры плохих слов: squirrel, canopy, monologue, prop, kiln, auction, locomotive, porcelain, vintage, automated). Глагол в скобках — всегда самый обычный (go, make, take, give, find, buy, send, open, clean, wait, ask…). Если сомневаешься, выбирай слово, которое знает школьник после двух лет изучения английского. Разнообразие делай через ситуации, людей и места, а не через редкие слова.

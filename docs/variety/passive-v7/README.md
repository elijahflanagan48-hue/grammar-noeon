Порядок пачек: сначала «Active или passive?» (B01–B06), затем особые конструкции, в конце — формы по временам.

## Почему сюжеты больше не будут повторяться

1. **Каталог сюжетов.** Перед заданиями Gemini пишет ~1000 конкретных сценариев по 25 сферам жизни. Скрипт отсеивает похожие и банальные.
2. **Один сюжет — одно задание.** Каждая пачка получает свой набор сюжетов. Повторно сюжет использовать нельзя, и скрипт это проверяет.
3. **Запрещённые банальные сюжеты.** Ремонт и стройка, «English is spoken», отменённая встреча и т. п. — список в `00-master.md`. Скрипт ловит их автоматически.
4. **Перекрёстный стоп-лист.** В каждый следующий промпт автоматически попадают уже использованные начала предложений, частые глаголы и имена.
5. **Проверка похожести.** Задания, слишком похожие на любое уже существующее (старое или новое), отклоняются.

# Карты правил (NOEON canvas)

У каждой темы, кроме обычного правила, есть большая карта на холсте. Движок общий: `noeon-canvas.js` + `noeon-canvas.css`. Метафора и оформление у каждой темы свои.

## Что умеет движок

| Мышь и тачпад | Палец |
|---|---|
| тянуть — перемещение | тянуть — перемещение, бросок — инерция |
| колесо — масштаб (после клика по карте; без клика колесо прокручивает страницу и карта показывает подсказку) | щипок — масштаб и перемещение двумя пальцами |
| Ctrl/⌘ + колесо, щипок тачпада — масштаб всегда | двойной тап по пустому месту — приблизить |
| двумя пальцами по тачпаду — перемещение | тап по объекту — `onTap` |
| двойной клик — приблизить; ← ↑ → ↓, + / −, 0 — вся карта, Esc | |

Ещё: миникарта (клик — перелёт), полный экран (холст переносится в `<body>`, Esc или ✕ — выход), карту нельзя увести за край, при повороте телефона центр остаётся на месте, плавные перелёты с учётом карточки справа (компьютер) или снизу (телефон), `prefers-reduced-motion`.

## Как сделать карту новой темы

1. Разметка: `noeonCanvasShell(id, ariaLabel, toolsHtml, helpText)` — вставить в страницу правила. В `toolsHtml` — свои поиск и режимы.
2. Содержимое: нарисовать мир фиксированного размера (W×H) — обычно один `<svg>` — и положить в `.nc-world`. Кликабельные объекты помечать `data-st`.
3. Запуск: `initialiseNoeonCanvas(box, { W, H, signal, onTap, onZoom, start })` возвращает `{ v, fit, flyTo, animateTo, zoomAt, say, setFull, isFull }`.
   - `onTap({ target, x, y })` — тап или клик без перемещения;
   - `onZoom(k)` — переключать уровни детализации классами;
   - карточка объекта — элемент `.nc-panel` внутри холста (движок не трогает жесты над ней).
4. Цветовые переменные темы задавать на самом холсте (`#id`), а не только на обёртке: в полноэкранном режиме холст живёт в `<body>`.
5. Файлы добавить в `index.html`, `sw.js` и `scripts/build_cloudflare.py`.

Пример — `infinitive-map.js` («Метро трёх форм»).

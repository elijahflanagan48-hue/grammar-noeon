# Conditionals: интеграция банка, 22 ноября 2026

Локально подключены все 804 задания из CD01–CD25. Версия: `conditionals-2026-11-22.1`. Банк собран в 9 частей, добавлено 1336 полей ответа; общий банк — 12658 заданий / 16295 полей. Исходные JSONL и тексты правила не изменены. Другие банки заданий и схема D1 сохранены. Пуш и деплой не выполнялись.

Приёмка выпуска не завершена: исходный банк не проходит требования покрытия, найден ошибочный принимаемый ответ; браузерные проверки блокируются ограничениями среды.

## Что подключено

11 целей практики по ячейкам C1–C11; фильтры меток конструкций и ссылки из карты; практика из теории и каталога; справка в тренировке. fact/which/mc используют multiple_choice, gap — open_brackets, mini — context_cloze, fix — error_fix, transform — transformation, order — word_order. Новые match/sort/bank/hunt работают через существующие поля ответа, черновики и проверку на сервере. Окончания match перемешиваются; hunt показывает исправления после проверки. Sort сохраняет все группы автора, включая задания с тремя группами.

Профиль `conditionals-exact-v1` принимает только заданные ключи, нормализуя регистр, пробелы, тип апострофа и конечные знаки препинания. Сокращения, варианты was/were и удаление already автоматически не выводятся. Реализации браузера, Worker и Python согласованы.

Ключи разделения свободной практики и назначений учитывают отдельные предложения, пары и исправления hunt; общая инструкция не резервирует весь формат. Непроверенный ученический снимок содержит только условие и элементы выбора, без ответов, объяснения или fixes.

- Общие проверки ответов: браузерный JS, Worker и Python совпадают на 12658 записях / 16295 полях / 52768 отправках. Проверены структура, ключи предложений, PWA и правило.

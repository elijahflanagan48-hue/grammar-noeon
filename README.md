# Grammar NOEON

Интерактивный русскоязычный справочник по английским временам с практикой, автоматической проверкой, объяснениями и ссылками на правила.

## Что уже внутри

- 5 больших разделов теории, полноэкранная интерактивная карта всех 12 форм с масштабированием, примерами, маркерами и случаями употребления;
- 1 115 публикуемых упражнений, 1 479 проверяемых ответов;
- 153 задания уровней B2–C2;
- 8 форматов: раскрытие скобок, перевод, выбор формы или значения, связность текста, исправление ошибки, трансформация и контекстный текст;
- объяснение после каждого ответа и переход к соответствующему правилу;
- в заданиях на раскрытие скобок ученик вводит только глагольные формы: подлежащие и дополнения всегда видны в условии;
- адаптивный интерфейс и локальная история результатов.

Полный перечень включённых тем и подтем приведён в [отчёте о покрытии теории](docs/THEORY-COVERAGE.md).

Сайт не требует сборки и внешних библиотек. Откройте его через любой статический HTTP-сервер, например:

```bash
python3 -m http.server 4175
```

Затем перейдите на `http://localhost:4175`.

## Проверка


## Обновление материалов

Исходные редакционные материалы не хранятся в этом репозитории. Публичный набор пересобирается из отдельного рабочего каталога:

```bash
python3 scripts/import_content.py --source /path/to/grammar-noeon
```

Импорт переносит только записи с `publishable: true`, удаляет внутренние сведения об источниках и делит банк упражнений на небольшие статические файлы. Проверка фиксирует ожидаемые объёмы и не пропускает служебные поля.

## Важное ограничение первой версии

Ответы и результаты работают в браузере: история хранится в `localStorage`, а проверочные данные загружаются на устройство ученика. Для личных кабинетов, назначений преподавателя и защищённого банка ответов потребуется отдельный серверный этап.

Теория использует British English. Уровни CEFR являются редакционной оценкой сложности, а не результатом внешней сертификации.

# Grammar NOEON

Веб-приложение для практики английской грамматики для русскоязычных учеников A1–C2. Интерфейс — русский, учебный контент — British English. [Рабочий сайт](https://grammar-noeon.grammar-noeon.workers.dev).

Банк: **9919 задания / 12538 полей**, 9 форматов.

| Формат | Название | Заданий |
|---|---|---|
| `active_to_passive` | Active → Passive | 100 |
| `context_cloze` | Пропуски в контекстном тексте | 373 |
| `direct_to_reported` | Direct → Reported | 782 |
| `modal_fix` | Исправление предложения | 50 |
| `modal_gap` | Пропуск: модальная форма | 700 |
| `modal_meaning` | Выбор значения в контексте | 50 |
| `multiple_choice` | Выбор формы / предложения | 905 |
| `open_brackets` | Раскрытие скобок | 6712 |
| `translation_ru_en` | Перевод | 247 |

Сложность: basic — 3420, medium — 4464, advanced — 2035.

Разделы: comparison — 1000, tenses — 4379, passive — 1000, modals — 1040, reported — 1000, nouns — 1000, speaking — 500.

Версии: `tenses-2026-11-09.1`, `comparison-2026-11-01.5`, `passive-2026-11-09.1`, `modals-2026-11-05.1`, `reported-2026-11-05.1`, `nouns-2026-11-07.1`, `speaking-2026-11-09.1`.

Локально подготовлены изменения банка; они ещё не опубликованы. [Отчёт о проверке](docs/review/V8-FINAL-2026-10-30/REPORT.md).

Выбор сложности использует только `level`: `basic` — «Базовый», `medium` — «Средний», `advanced` — «Продвинутый». Уровень отражает сложность текста, а не название времени. `cefr_estimate` сохранён как историческая метаинформация и в текущем клиенте/Worker не участвует в подборе. Неизменённые записи сохраняют собственные версии.

Теория, карта времён и главная доступны гостю. Учитель создаёт приглашения и назначения, управляет доступом ученика к свободной тренировке, смотрит историю и отчёты. Свободная тренировка ученика по умолчанию запрещена и включается учителем индивидуально. Ученик получает только выбранные задания без ключей; ответ текущего задания открывается после собственной проверки. Полный банк с ключами доступен учителю.

Проверка и сохранение выполняются Worker на сервере. Выданные задания хранят собственные снимки и версии, старые оценки не пересчитываются после редакции банка. История загружается лёгкими сводками, ошибки по теме — отдельным запросом. Учитель может задать видимое ему имя ученика, отключить кабинет с сохранением истории, включить его снова и отозвать действующее приглашение. В списке учеников доступны сортировка, последняя активность и невыполненные назначения; отключённые кабинеты находятся в свёрнутом архиве. Ежедневная очистка удаляет истёкшие сессии и ограничения запросов, а также приглашения, истёкшие более месяца назад. Отчёты, черновики и уведомления доступны в кабинетах.

Для новых проверенных ответов конкретная причина ошибки показывается перед общим правилом, если удалось однозначно распознать согласование, форму после did, been/being или пропуск вспомогательного глагола. Этот разбор сохраняется с ответом и доступен в отчёте. При неоднозначности остаётся общее объяснение; старые работы не получают новый разбор задним числом.

На «Сегодня», в кабинете и в списке учеников преподавателю доступна очередь «Ожидают моей проверки». В неё входят переводы из завершённых работ активных учеников, включая старые неизвестные системе варианты. В отчёте рядом с условием и ответом доступны «Зачесть» / «Не зачесть» и необязательный комментарий. Решение обновляет баллы и очередь, а ученик получает уведомление со ссылкой на точный ответ. Исправление решения создаёт новое непрочитанное уведомление; предыдущее решение остаётся в журнале преподавателя. При нескольких полях каждое оценивается отдельно. Пока есть непроверенные поля перевода, образец ученику не раскрывается.

## Устройство и состояние выпуска

Клиент работает без сборки: корневые HTML/CSS/JS, теория и JSON. Сервер — Cloudflare Worker, D1 и Firebase Auth. Источник истины — корневые файлы; `cloudflare/public/` и `cloudflare/generated/` создаются командой `npm run build:cloudflare`, вручную их не редактируют.

На рабочем сайте опубликованы этапы 9–12: исправленный банк, актуальные автопроверки и офлайн-манифест, лёгкая история и управление учениками. Миграция 0008 применена после резервного копирования; старые данные сохранены. [Текущее состояние](PROJECT-STATUS.md), [журнал выпусков](docs/CHANGELOG.md).

Этап 12 опубликован: «Сегодня» использует один лёгкий запрос `/api/today`. Ученик видит продолжение начатой работы, новые назначения, слабые темы и недельные показатели; учитель — новые выполненные работы и учеников/назначения, требующих внимания. Гость видит только описание и доступные действия. Аккаунтные тренировки больше не дублируются в локальной истории, серверные снимки и оценки сохраняются.

PWA хранит оболочку, теорию и публичный `data/exercises/index.json`. При офлайн-перезагрузке манифест доступен для справочных данных; гостевая главная не показывает размеры банка или локальный прогресс. Для данных аккаунта на «Сегодня» требуется соединение. API и `part-*.json` никогда не кэшируются; тренировки требуют соединения.

Кнопка «Случайная замена» перебирает новые варианты только по исходным фильтрам, не меняя остальные позиции. Уже показанные варианты не повторяются, пока есть другие доступные; затем перебор начинается заново.

Перед назначением учитель проверяет весь набор: может раскрыть ответы и объяснения, заменить или убрать упражнения и добавить новые через поиск. Поиск можно расширить на весь раздел без потери уже выбранных заданий. Ученик получает набор только после «Отправить ученику»; порядок сохраняется. Если набор или редакция банка изменились параллельно, отправка отклоняется с пояснением. До отправки набор хранится только в открытой вкладке; перезагрузка его сбрасывает.

## Как запустить локально

Нужны Node.js 22 и Python 3.12. Python-пакеты для проверок не требуются.

```bash
npm ci
npm run dev
```

Откройте `http://127.0.0.1:4175/#profile`. Используется настоящий Worker в Miniflare с временной изолированной D1 и тестовой службой входа, без подключения к Firebase или Cloudflare. `GRAMMAR_PORT` меняет локальный порт.

Тестовый учитель: `teacher@example.test`, ученик: `anna@example.test`. Пароль обоих: `FictionalPassword!2026`. Войдите учителем, откройте ученика и разрешите свободную тренировку либо создайте назначение. Затем войдите учеником в отдельном профиле браузера. Перезапуск удаляет данные демонстрации; отправка писем имитируется. Сервис слушает только локальный адрес, облачные настройки и пароли не читает.

`server/` и `run.py` — устаревшая Python-реализация. Она сохранена для регрессий исторической проверки, не поддерживает актуальную свободную тренировку ученика и больше не развивается. Для разработки используйте Miniflare-команду выше. Обычный статический сервер не обеспечивает защиту банка и для публикации не подходит.

## Как проверить

```bash
npm test
```

Команда пересобирает производные файлы, проверяет документацию и банк, запускает Python unittest и все локальные `tests/*.mjs`. Внешние HTTP-запросы запрещены; Miniflare использует только локальные порты и тестовую службу входа. Если Miniflare отсутствует, зависимые тесты явно пропускаются; после `npm ci` он установлен и проверки обязательны. Браузер для основной команды не нужен. `PYTHON` позволяет указать путь к Python.

Полная браузерная приёмка запускается отдельно:

```bash
npx playwright install chromium
npm run test:browser
```

Она проверяет PWA и кабинеты на мобильном и настольном экране в светлой и тёмной темах. Для установленного Chrome можно задать `GRAMMAR_CHROME_PATH`. Тестовые аккаунты используют домен `example.test`.

`npm run test:live` выводит список отдельных сетевых тестов. Запуск выбранного: `npm run test:live -- имя-файла [аргументы]`. Они не входят в `npm test` и требуют отдельного решения владельца. Изменяющие данные сценарии используют только выделенный тестовый Worker и вымышленные аккаунты; некоторым требуется `GRAMMAR_TEST_FIXTURES` с тестовыми сессиями. Такие файлы не добавляют в репозиторий.

## Modal Verbs

Раздел `#theory/modals` содержит 11 частей правила; практика `#practice/modals` — 1000 одиночных упражнений и 40 мини-текстов. Можно выбрать весь раздел, группу правила или одну/несколько из 31 подтемы, уровни и форматы. Пропуски используют авторские варианты выбора; исправление ошибки — ввод полного предложения. Тексты оцениваются по каждому пропуску.

Исходный пакет хранится отдельно в основном каталоге `content/modal-verbs/source/`; `scripts/build_modal_verbs.py` применяет проверенные редакционные поправки к производным данным. Не добавляйте batch-файлы второй раз: все 40 текстов уже включены в итоговый JSONL. Проверка `modal-exact-v1` принимает только канонический ответ и перечисленные варианты после нормализации регистра, пробелов, апострофа и конечного .!?; старые задания сохраняют свои профили.

## Материалы, версии и документация

Актуальные версии разделов, объёмы и состав банка задаёт `data/exercises/index.json`. Записи сохраняют собственную `content_version`: в разделе допустимы прежние редакции неизменённых заданий. Проверки отклоняют неверные версии и версии новее манифеста. Новая редакция изменяет версии только нужных заданий и соответствующего раздела.

После правок банка выполните `npm run docs:update`, затем `npm test`. Таблица выше и блок состояния генерируются из манифеста скриптом `scripts/update_docs.py`; числа вручную не правят. Текст README редактируют в `docs/README.template.md`. `npm run docs:check` проверяет актуальность документации.

Не запускайте исторический импорт материалов для обычной правки ключей: это отдельное пересоздание банка из источников. Синхронизированные исходные материалы остаются только для чтения.

## Как публиковать

Публикацию выполняет владелец после отдельного разрешения и приёмки локального архива. Сначала обновить версии ресурсов и `CACHE`, если менялся клиент, выполнить `npm run docs:update`, `npm test` и `npm run test:browser`. Перед миграциями или операциями над рабочими записями сохранить резервную копию D1 средствами проекта; новые изменения схемы оформлять только аддитивными миграциями.

```bash
npm run build:cloudflare
npx wrangler deploy --config cloudflare/wrangler.jsonc --dry-run
```

Проверить имя Worker и привязку D1 в конфигурации. В рабочей базе проекта миграция 0008 уже применена. Для отдельной существующей базы, ещё не обновлённой до этапа 11, обязательна аддитивная миграция `cloudflare/migrations/0008_light_history_and_students.sql`: после резервной копии и отдельного разрешения владельца применить её один раз к нужной существующей БД перед развёртыванием нового Worker. `schema.sql` предназначен для новой пустой БД и не заменяет миграцию. Удалённые команды не входят в локальные тесты.

После отдельного разрешения владельца:

```bash
npx wrangler deploy --config cloudflare/wrangler.jsonc --keep-vars
```

Рабочие секреты Firebase и код владельца настраиваются отдельно и сохраняются благодаря `--keep-vars`. Не подменяйте их тестовой службой входа. Миграции и сетевые приёмочные проверки выполняются отдельно по согласованному плану; `npm test` ничего не публикует и рабочую БД не изменяет. После выпуска записать фактическую версию и результаты в журнал.
